# Folder Structure

- backend/app/api – API route modules
- backend/app/ai – detection service and AI-specific logic
- backend/app/llm – assistant wrapper
- backend/app/rag – retrieval and knowledge base integration
- backend/app/reports – PDF generation logic
- backend/app/schemas – request and response models
- backend/app/database – database connection and base classes
- frontend/src/components – shared UI building blocks
- frontend/src/pages – route-level screens
- frontend/src/services – API client layer
- knowledge_base – local medical knowledge documents
- uploads – uploaded case images
- vector_db – generated vector storage
- reports – generated reports
